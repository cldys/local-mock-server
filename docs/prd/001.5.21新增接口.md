# 5.21 新增接口

## 接口概览

| 项目 | 说明 |
| --- | --- |
| 接口名称 | 折扣活动详情 |
| 请求方法 | `POST` |
| 请求路径 | `/api/api/v1/discountActivityDetail` |
| Mock 文件 | `src/mocks/POST/api.api.v1.discountActivityDetail.mock.js` |

## 请求参数

请求参数放在请求体中，以下字段均为非必填。

| 字段 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `customerNo` | `string` | 否 | 客户号，用于按客户筛选 |
| `memberNo` | `string` | 否 | 会员号，用于按会员筛选 |
| `orderCreateStartTime` | `string` | 否 | 订单创建开始时间 |
| `orderCreateEndTime` | `string` | 否 | 订单创建结束时间 |

请求体示例：

```json
{
  "customerNo": "CUSTOMER-1001",
  "memberNo": "MEMBER-1001",
  "orderCreateStartTime": "2026-05-01 00:00:00",
  "orderCreateEndTime": "2026-05-21 23:59:59"
}
```

## 响应格式

该接口返回原始业务数据，不使用项目默认的 `code`、`message`、`data` 统一响应包装。

```json
{
  "total": 20,
  "data": [
    {
      "customerNo": "CUSTOMER-1001",
      "orderNo": "ORDER-1001",
      "orderCreateTime": "2026-05-21 10:30:00",
      "orderStatus": "paid",
      "skuId": "SKU-1001",
      "skuName": "示例商品",
      "originalPrice": 199.99,
      "discountPrice": 159.99,
      "discount": 0.8,
      "customerActualPayPrice": 149.99,
      "settlementPrice": 145.99,
      "subsidyPrice": 10
    }
  ]
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `total` | `number` | 数据总条数 |
| `data` | `array` | 折扣活动详情列表 |

### `data` 列表项字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `customerNo` | `string` | 客户号 |
| `orderNo` | `string` | 订单号 |
| `orderCreateTime` | `string` | 订单创建时间 |
| `orderStatus` | `string` | 订单状态 |
| `skuId` | `string` | SKU ID |
| `skuName` | `string` | SKU 名称 |
| `originalPrice` | `number` | 原价 |
| `discountPrice` | `number` | 折扣价 |
| `discount` | `number` | 折扣 |
| `customerActualPayPrice` | `number` | 客户实际支付价 |
| `settlementPrice` | `number` | 结算价 |
| `subsidyPrice` | `number` | 补贴价 |

## Mock 实现要求

根据项目 README，新增接口应通过 `.mock.js` 文件实现。该接口要求直接返回原始业务数据，Mock 配置中需要显式声明 `raw: true`，避免被自动包装成统一响应格式。

```js
module.exports = {
  raw: true,
  default: {
    total: 20,
    data: [
      {
        customerNo: "CUSTOMER-1001",
        orderNo: "ORDER-1001",
        orderCreateTime: "2026-05-21 10:30:00",
        orderStatus: "paid",
        skuId: "SKU-1001",
        skuName: "示例商品",
        originalPrice: 199.99,
        discountPrice: 159.99,
        discount: 0.8,
        customerActualPayPrice: 149.99,
        settlementPrice: 145.99,
        subsidyPrice: 10
      }
    ]
  }
};
```
