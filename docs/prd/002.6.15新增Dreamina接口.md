# 6.15 新增 Dreamina 接口

## 接口概览

本次新增 3 个 Dreamina 生成相关 mock 接口，用于支持前端文生图、文生视频和任务进度查询。

| 接口名称 | 请求方法 | 请求路径 | Mock 文件 |
| --- | --- | --- | --- |
| 文生图任务创建 | `POST` | `/api/v1/dreamina/textToImage` | `src/mocks/POST/api.v1.dreamina.textToImage.mock.js` |
| 文生视频任务创建 | `POST` | `/api/v1/dreamina/textToVideo` | `src/mocks/POST/api.v1.dreamina.textToVideo.mock.js` |
| 生成任务查询 | `GET` | `/api/v1/dreamina/generationProcess?taskId=${id}` | `src/mocks/GET/api.v1.dreamina.generationProcess.mock.js` |

## 1. 文生图任务创建

### 功能说明

创建图片生成任务。接口不会直接返回图片结果，只返回图片任务 ID 和 `PENDING` 状态，前端需要继续调用任务查询接口获取生成结果。

### 请求参数

请求参数放在请求体中。

| 字段 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `prompt` | `string` | 是 | 图片生成提示词 |
| `count` | `number` | 是 | 生成数量 |

请求体示例：

```json
{
  "prompt": "一张未来城市海报",
  "count": 4
}
```

### 响应格式

```json
{
  "requestId": "b7079936-845c-42cb-8647-dd41ecae38b3",
  "code": "00",
  "data": {
    "taskId": "img-951c8d0ab6be4dcab3441a28896cd571",
    "type": "IMAGE_GENERATION",
    "status": "PENDING"
  },
  "success": true
}
```

## 2. 文生视频任务创建

### 功能说明

创建视频生成任务。接口不会直接返回视频结果，只返回视频任务 ID 和 `PENDING` 状态，前端需要继续调用任务查询接口获取生成结果。

### 请求参数

请求参数放在请求体中。

| 字段 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `prompt` | `string` | 是 | 视频生成提示词 |
| `count` | `number` | 是 | 生成数量 |

请求体示例：

```json
{
  "prompt": "一段未来城市夜景的电影感运镜视频",
  "count": 1
}
```

### 响应格式


## 3. 生成任务查询

### 功能说明

根据任务 ID 查询生成结果。当前 mock 不做任务状态存储，直接返回 `COMPLETED` 状态。

- `taskId` 以 `img-` 开头时返回图片任务结果。
- 其他 `taskId` 返回视频任务结果。
- 视频任务的 `details` 只返回 1 项。
- 图片任务的 `details` 返回 4 项。
- 图片和视频资源地址会根据当前请求 host 动态生成，指向项目内置 `/mock-assets` 资源。

### 请求参数

请求参数放在 query 中。

| 字段 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `taskId` | `string` | 是 | 图片或视频生成任务 ID |

请求示例：

```text
GET /api/v1/dreamina/generationProcess?taskId=vid-555ad1f3f89d4b58b639ae343b147d59
GET /api/v1/dreamina/generationProcess?taskId=img-951c8d0ab6be4dcab3441a28896cd571
```

## Mock 实现要求

这 3 个接口都返回后端原始业务结构，Mock 配置中均声明 `raw: true`，避免被项目默认的 `code`、`message`、`data` 格式二次包装。

任务创建接口只校验 `prompt` 和 `count` 是否存在；任务查询接口只校验 `taskId` 是否存在。当前不增加轮询状态变化、失败场景或任务缓存，保持与现有 mock 实现一致的简单静态返回。
